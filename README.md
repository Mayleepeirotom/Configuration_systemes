# Configuration_systemes

Rapport d'un projet en binome :
Pour ce projet, nous devions créer une **notice utilisateur** qui permettrait à notre client de configurer complètement un poste et d'y installer les logiciels de bureautique les plus courants ou configurer une imprimante par exemple. 

Le PDF étant trop lourd, je l'ai coupé en quatre parties. Pour cette simple notice, nous obtenons la note de **16/20**.

Ce projet de sciences réseaux dure toute l'année alors une énorme partie de celui-ci n'est pas encore doccumentée, de même pour la note qui sera donnée uniquement à l'issue d'une soutenance lors de la semaine du 16 juin.
